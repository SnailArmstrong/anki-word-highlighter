Note: This is a Chrome Manifest V3 browser extension, not a web app. The pages above show the static UI, but interactive features (AnkiConnect sync, content script highlighting, Chrome storage) only work when loaded as an unpacked extension in Chrome. To use the extension: open chrome://extensions, enable Developer Mode, click "Load unpacked", and select this folder.
