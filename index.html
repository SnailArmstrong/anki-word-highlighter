Anki Spanish Sync

Chrome Extension — Vocabulary Highlighter for Anki

This is a Chrome browser extension (Manifest V3) that highlights Spanish vocabulary words on any web page based on your Anki learning status. It syncs with AnkiConnect (running locally on port 8765) and annotates words as Learning, Mature, or Unknown.

🧩

Popup UI

Extension popup with annotation toggles, style mode, and color pickers for each word category.
⚙️

Settings Page

Deck & field selection, Yomitan dictionary import, and suspended card handling.
Preview note: The UI is served statically with mock Chrome APIs so you can see and interact with the interface. Full functionality — AnkiConnect sync, content-script annotation, and chrome.storage persistence — requires loading this as an unpacked extension in Chrome at chrome://extensions.
